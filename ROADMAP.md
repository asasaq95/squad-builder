# Squad Builder Roadmap

Personal use only. No store publishing.

## 1. Plumbing (do first)

- Permanent signing key stored as a repository secret and used by the workflow, so each new version installs over the old one and keeps saved squads.
- Real version numbers (versionCode and versionName) bumped on every release.
- In-app check that compares the installed version with the latest release on GitHub.

## 2. Features

- Drag and drop players between positions.
- Custom formation editor beyond the ten presets.
- Club colours per team.
- Export the board as a shareable image (PNG).
- Arabic interface with right to left layout.
- Later: player photos and live squad data, pending licensing checks.

## 3. Match day

- Lineup mode: pick the starting eleven from the squad, mark the captain, list the bench.
- Clean teamsheet image to share before the game.
- Substitution planner: who replaces whom, and in which minute.

## 4. Quality of life

- Share button that sends the board straight to WhatsApp as an image.
- Light theme for daytime.
- Home screen widget showing the current first eleven.
- QR code transfer between phone and laptop, no cloud account.

## 5. Ideas borrowed from similar apps (to pick from)

- Small-sided mode: 5, 6 or 7 players on a smaller pitch, for futsal and friendly games.
- Tactical arrows drawn on the pitch to show player movement.
- Captain armband badge on the marker.
- Kit editor: shirt colour, sleeve colour and number colour per team.
- Pitch style options: grass, dark, chalkboard.
- Export sizes: square for social apps and 4K for printing.
- Share link or QR that reopens the exact same lineup on another device.
